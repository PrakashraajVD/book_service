# Initialize the Server

- Built an `Axum` based web service inside the `book_service`` crate within the `rest_api_workspace` Rust workspace

- Used `tracing_subscriber::EnvFilter` to filter spans and events based the given set of filter directives, `info,tower_http=warn,axum=warn,toasty=warn,tokio_postgres=warn` Change it (log level) to just `trace`, rerun the application, and trigger the curl request. Now, you can see all trace logs generated by `Axum` and 3rd party crates.

- To improve developer productivity, we use `Just`, a modern command runner and alternative to `Make`.

- Run `just book app` to run the server.
- Run `just book lint` to run cargo fmt and clippy on the book_service package.

# Configuration and Middleware

- Used environment variables to configure the application
- Used `envconfig` to initialize configuration `struct` from environment variables on application start, and immediately panic if no configuration is set
- Then, pass the `struct` to the router via `AppState` to use it to configure middleware.

## Server Middleware

- Save above configuration `struct` inside `AppState` to use it to configure the server and
  middleware
- Used `tower` and `tower-http` ecosystem to add `CORS(Cross Origin Resource Sharing), request ID` and `trace` middleware

# Database Design

- A simple postgres table named `books` is used
- Mapped `TIMESTAMPTZ`, `DATE`, `UUID` types to `jiff::{Timestamp, civil::Date}`, `uuid::Uuid` Rust types
